# Tec.Lunatico
this is the repository that holds the team's test code for future upgrades and fixes
both python codes are text writted in spanish.

we got a few files, two .db data bases from sqlite and two python files, the astronaut.db database is the one that will go into the astronaut's suit and will connect into the local computer for the python test.py, the python test uses the tec_lunatico.db database to compare the incoming data from the stored python test_2.py to the comparative and send out the alert.

at this moment, test.py can be tested fully, by inserting in the terminal "python test.py" and following the instructions, select one of the measurable values like "globulos_blancos" then inserting the number that came in from the astronaut's suit data base, it will tell you if the number is too high=risky or too low=risky or in between the parameters.

the test_2.py is one of the many steps ahead to keep working on, since it will use a built in compatible computer to store data and send it near proximity by methods like bluetooth low energy connection or others, for the comparative python to compare and the local ai to interpret and talk with the astronaut.
